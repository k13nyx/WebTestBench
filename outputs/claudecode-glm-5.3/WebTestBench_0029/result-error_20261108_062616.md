# QA Test Report — My Reading Library (http://localhost:6029/)

**Summary:** 20 items executed — **17 PASS / 3 FAIL** (FT-02, FT-09, FT-12). All testing performed via Playwright DOM interaction only (no screenshots, no page refreshes; a `window.__noReload` sentinel proved no reload occurred during any interaction).

## Functionality (FT)

- [X] **FT-01: Add a new book with full details**
  - **Action:** Open "Add Book", fill in Title, Author, Genre, Total Pages, and Notes; save.
  - **Expected:** The new book appears in the "To Read" list with all entered details.
  - **Result:** Added "The Martian" (Andy Weir, Science Fiction, 368 pages, with notes). Book appeared in To Read with all details displayed. PASS.

- [ ] **FT-02: Update reading progress (current page 50 of 200)**
  - **Action:** Update a book's reading progress to page 50 of 200.
  - **Expected:** Progress is stored and displayed (25% or "50 / 200 pages").
  - **Bug Report**
    - **Issue:** There is no functional way to update reading progress. The dedicated progress-update UI is unreachable (clicking the progress display on the card does nothing — the `ProgressModal` component is never triggered), and the fallback "Edit Details" dialog opens with **stale form state from the previously-opened book**, so updating only the page field would overwrite the book with another book's data.
    - **Actual:** Opening Edit Details for "1984" initially displayed "Foundation"'s data; the card could only be made to show "50 / 200 pages" by manually re-entering ALL of 1984's fields (title, author, genre, status, cover, notes, total pages) before saving. The same stale-state defect affects the Rate & Review dialog: opening it for "The Hobbit" (no rating/review) showed The Great Gatsby's 5-star rating and review text pre-filled, and clicking "Save Review" without selecting any star saved that stale 5★ rating and Gatsby's review onto "The Name of the Wind" (avg rating stat jumped 4.6 → 4.7).

- [ ] **FT-12: Combine genre + status + rating (min 4) filters**
  - **Action:** Set Genre = Classic Fiction, Status = Completed, Rating = "4+ Stars".
  - **Expected:** Books matching all filters are displayed (rating ≥ 4).
  - **Bug Report**
    - **Issue:** The rating filter performs an **exact-value match instead of a minimum ("4+") match** (`book.rating !== filters.rating` strict equality against a single value in `useBooks.ts`), contradicting the "4+ Stars" label.
    - **Actual:** With Genre = Classic Fiction + Status = Completed + Rating = "4+ Stars", the list shows **"No books found — Try adjusting your filters"**, although The Great Gatsby and To Kill a Mockingbird (both Classic Fiction, Completed, 5★) satisfy "at least 4 stars". Conversely, Project Hail Mary (Science Fiction, Completed, exactly 4★) does display under the same filters — confirming the filter matches only ratings equal to exactly 4, not ≥ 4.

- [X] **CS-02: Empty Title/Author rejected**
  - **Action:** Submit the Add Book form with empty Title and Author.
  - **Expected:** Submission rejected with a validation message; no book created.
  - **Result:** Native validation blocked submission (`validity.valueMissing`, message "Please fill out this field."); modal stayed open; total book count unchanged. PASS.

- [X] **CS-03: Invalid progress rejected/clamped**
  - **Action:** Enter invalid current page values: 300 (150% of 200), 250 of 200, and −10; attempt to save each.
  - **Expected:** Invalid values are rejected or clamped.
  - **Result:** All three rejected by native validation — 300 and 250: `rangeOverflow`, "Value must be less than or equal to 200."; −10: `rangeUnderflow`, "Value must be greater than or equal to 0."; the dialog stayed open and the book's progress remained unchanged on each attempt. PASS.

- [X] **CS-04: Rating scale 1–5 only**
  - **Action:** Attempt to enter ratings outside the 1–5 scale.
  - **Expected:** Ratings outside 1–5 cannot be entered/saved.
  - **Result:** The widget offers exactly 5 stars (clicks set 1–5 only); there is no mechanism to enter 0, 6, or negative values, and the save handler refuses a 0 rating. PASS.
