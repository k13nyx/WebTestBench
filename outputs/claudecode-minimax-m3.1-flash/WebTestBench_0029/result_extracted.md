# Test Result

## Functionality

- [X] FT-01: Add a book with title, author, and genre
  - Action: Click "Add Book", enter a title, an author, and a genre, submit the form.
  - Expected: The form closes/saves, and the new book appears in the "To Read" list showing its title, author, and genre.
- [ ] FT-02: Notes field is optional on add
  - Action: Add a book leaving the "Notes" field empty; then add another book with notes text.
  - Expected: Both books are saved successfully; the first shows no notes without an error, the second shows its notes text.
  - Bug Report:
    - Issue: Incorrect Data Binding (stale form state) / Notes not surfaced per book
    - Actual: Both saves succeed with no error ("Book Added", counts 11 → 12, cards show correct title/author/genre), but notes are never displayed for a specific book — the card has no notes field, and the only notes UI (Edit Details dialog) shows another book's data: opening "Edit Details" for the book added *without* notes displayed title "Notes Test B", author "Notes Author B" and notes "Beta note marker 42" (the other book's values), while the actual book card shows only "Notes Test A / Notes Author A / Reading / Fantasy".
- [X] FT-03: Update reading progress using percentage or page count
  - Action: Open a book in "Currently Reading", enter a progress value (percentage) and separately a page count, and save.
  - Expected: The book card/detail shows the saved progress (percentage and/or pages) and the updated value is reflected in the library view.
- [ ] FT-04: Set start date and finish date
  - Action: Open a book, set a "Start Date" and a "Finish Date", and save.
  - Expected: Both dates are displayed on the book's card/detail after saving and after reloading the page.
  - Bug Report:
    - Issue: Missing Feature / No Persistence
    - Actual: No date input exists anywhere in the app (`document.querySelectorAll('input[type=date]').length === 0`; the Add/Edit Book forms contain only Title, Author, Genre, Status, Total Pages, Current Page, Cover URL, Notes). "Started:"/"Finished:" dates can only be auto-generated by the app when the status changes (e.g. "Started: 11/7/2026"), and no value survives a reload — after `reload()` the library reverts to the 10 seed books (Dune back to 412/688 pages, The Midnight Library back to "To Read", Gatsby back to 5 stars, added books gone, `localStorage` empty).
- [X] FT-05: Move a book to "Currently Reading"
  - Action: Change the status of a book in "To Read" to "Currently Reading".
  - Expected: The book appears in the "Currently Reading" list and no longer appears in "To Read".
- [X] FT-06: Move a book to "Completed"
  - Action: Change the status of a book in "Currently Reading" to "Completed".
  - Expected: The book appears in the "Completed" list and no longer appears in "Currently Reading".
- [X] FT-07: Give a rating and write a review for a completed book
  - Action: Open a book with status "Completed", select a star rating, type review text in the review field, and save.
  - Expected: The selected rating and the review text are displayed for that book and are retrievable when reopening it.
- [ ] FT-08: Completed books appear in reading history
  - Action: Complete a book with a rating and review, then open the "Reading History" section.
  - Expected: A history entry exists for that book showing its title, author, rating, review text, and completion/finish date.
  - Bug Report:
    - Issue: Missing Feature (no Reading History section)
    - Actual: There is no "Reading History" section anywhere in the UI. `http://localhost:6029/history` returns the app's 404 page ("Oops! Page not found"), the app has only two routes (Index, NotFound), and the only occurrence of the word "history" in the page is the recommendation subtitle "Based on your reading history and favorite genres". Completing a book only shows a transient "Rate & Review" dialog; no history entry is created or listed.
- [ ] FT-09: Edit an existing rating and review in reading history
  - Action: In "Reading History", open the Edit control on a rated/reviewed book, change the rating and the review text, and save.
  - Expected: The history entry shows the new rating and new review text; the old values are not displayed.
  - Bug Report:
    - Issue: Missing Feature (no Reading History section / no Edit control)
    - Actual: No "Reading History" section exists, so no Edit control can be opened there. Rating/review editing is only reachable from a completed book's card menu ("Edit Review"), where changing the rating and text works — but there is no history entry to update and no history-specific edit/delete affordance.
- [ ] FT-10: Delete a rating/review from reading history
  - Action: In "Reading History", click Delete on a book that has a rating and review, and confirm.
  - Expected: The rating and review are removed from that history entry and the entry no longer displays them.
  - Bug Report:
    - Issue: Missing Feature (no Delete control for a rating/review)
    - Actual: There is no "Reading History" section and no Delete control for a rating or review anywhere. The card menus offer only "Edit Details", "Start Reading"/"Mark as Completed", "Edit Review" and "Remove from Library" — the only removal path deletes the entire book from the library, not just its rating/review.
- [X] FT-11: Recommendations based on most-read genre and highly rated books
  - Action: Have several books in the library, with multiple books in one genre and other books rated 4–5 stars, then open the "Recommendations" section.
  - Expected: Recommended titles are drawn only from the user's own library and reflect the top genre and/or the highly rated books.
- [X] FT-12: Search the library by title or author
  - Action: Type a word appearing in a book title in the search field, then a word appearing in an author name.
  - Expected: Only matching books are shown for each query, and clearing the search restores the full library.
- [ ] FT-13: Combine genre, status, and rating filters
  - Action: Select a genre, a status, and a minimum rating in the filter controls together.
  - Expected: Only books matching all three conditions are listed, and changing or clearing any filter updates the result list accordingly.
  - Bug Report:
    - Issue: Incorrect Filter Logic (rating filter is an exact match, not a minimum)
    - Actual: Genre and Status combine correctly (Classic Fiction + Completed + rating → "The Great Gatsby"; Fantasy + To Read → "The Hobbit", "The Name of the Wind"), and filters/clearing update live ("Filters active / Clear all"), but the rating filter matches the rating exactly instead of as a minimum: with books rated 5 (To Kill a Mockingbird, Sapiens) and 4 (The Great Gatsby, Project Hail Mary, Atomic Habits), the "4+ Stars" filter returned only the three 4-star books and excluded the 5-star ones, while "3+ Stars" and "2+ Stars" returned "No books found" even though books rated 4–5 exist.

## Constraint

- [X] CS-01: Required fields are enforced when adding a book
  - Action: Attempt to submit the Add Book form with title, author, and genre each omitted one at a time.
  - Expected: Each attempt shows a validation error on the missing field and no book is created.
- [X] CS-02: Progress percentage is bounded to 0–100
  - Action: Enter a progress percentage of 0, 100, and an out-of-range value such as 150, then save.
  - Expected: 0 and 100 are accepted, the out-of-range value is rejected with an error (or clamped to a valid value) and never saved as 150.
- [X] CS-03: Rating is limited to completed books and a valid star range
  - Action: Open a book whose status is "To Read" or "Currently Reading" and attempt to submit a rating; then on a completed book attempt to select a rating outside the 1–5 star range.
  - Expected: Rating cannot be submitted for a book that is not completed, and only a valid 1–5 star rating is accepted.

## Interaction

- [X] IX-01: Status lists and counts update immediately on a status change
  - Action: Move a book between "To Read", "Currently Reading", and "Completed" and watch the lists and their item counts.
  - Expected: The book appears in the destination list, disappears from the origin list, and the displayed counts update without a page reload.
- [X] IX-02: Search/filter results update live and show an empty state when nothing matches
  - Action: Type a nonsense string in the search field, then apply filters for a genre/status/rating combination that matches no book.
  - Expected: The result list updates as the input changes and a clear "no books match" message is shown instead of an empty or broken area.

## Content

- [ ] CT-01: Book details display the correct saved data
  - Action: Open a book in the library and compare the displayed title, author, genre, status, progress, notes, start date, and finish date against the values entered.
  - Expected: Every displayed field matches the saved values exactly, with no blank or placeholder text where data exists.
  - Bug Report:
    - Issue: Incorrect Form Binding (Edit Details does not load the selected book) / Missing Notes Display
    - Actual: Opening "Edit Details" for an existing book shows blank/incorrect data instead of the saved values — for The Midnight Library the Title and Author inputs are empty and Genre shows "Classic Fiction" (actual: Contemporary Fiction) and Total Pages 300 (actual: 304); for Dune the inputs are empty with Total Pages 300 (actual: 688). The form keeps the previously typed values (the Add Book dialog even opens prefilled with the last edited book, e.g. "Dune / Frank Herbert / 688 / 999 / Science Fiction / reading"). Notes are never displayed for a book anywhere, and the card itself shows notes as nothing at all.
- [ ] CT-02: History and recommendation entries show relevant, meaningful content
  - Action: Review the "Reading History" and "Recommendations" sections.
  - Expected: History entries show the exact review text and star rating entered, and each recommendation displays book details (title, author, genre) plus an indication of why it was recommended; no lorem ipsum or unrelated filler text appears.
  - Bug Report:
    - Issue: Missing Feature (no history entries) / Missing Recommendation Reason
    - Actual: No "Reading History" section exists, so there are no history entries showing the exact review text and star rating. The Recommendations section is populated with meaningful, real library content ("Dune Messiah | Frank Herbert | Science Fiction", "The Hobbit | J.R.R. Tolkien | Fantasy", "The Name of the Wind | Patrick Rothfuss | Fantasy" — all titles present in the library, no lorem ipsum), but each recommendation shows only title, author and genre with no indication of why it was recommended (no "because you read…"/"similar to…" text); the only explanation is the single section-wide subtitle "Based on your reading history and favorite genres".
