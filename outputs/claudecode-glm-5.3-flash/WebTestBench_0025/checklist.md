# 测试检查清单

## 功能性
- [ ] FT-01：页面加载时显示预定义的创意类别，包括短篇故事、诗歌、角色素描、奇幻风景和头脑风暴主题。
  - 操作：在全新的浏览器会话中打开网页并查看类别选择区域。
  - 预期：五个默认类别中的每一个（短篇故事、诗歌、角色素描、奇幻风景、头脑风暴主题）都是可见的且可供选择。

- [ ] FT-02：用户可以选择一个类别并在其中生成随机提示。
  - 操作：点击“短篇故事”类别，然后点击生成按钮。
  - 预期：屏幕上出现一个与所选类别相关的随机提示文本。

- [ ] FT-03：生成的内容在每个类别中都会产生明显不同的输出。
  - 操作：分别为“诗歌”、“奇幻风景”和“头脑风暴主题”生成提示。
  - 预期：每个类别生成的提示符合该类别（例如，“诗歌”是诗歌主题的，“奇幻风景”是风景主题的），而不是通用或重复相同的句子。

- [ ] FT-04：连续两次在同一类别中生成会返回不同的提示。
  - 操作：在单个类别中，生成一个提示，记录下来，然后再次点击生成；最多重复 5 次。
  - 预期：至少有一个后续提示与前一个提示文本不同。

- [ ] FT-05：用户可以标记提示为收藏，并且该提示会被添加到收藏列表中。
  - 操作：生成一个提示，然后点击该提示上的收藏/星形图标。
  - 预期：该提示出现在专门的收藏区域中，并且图标上具有视觉激活/选中状态。

- [ ] FT-06：用户可以取消收藏提示并将其从收藏中移除。
  - 操作：点击已收藏提示上的切换开关（再次点击其星形图标）。
  - 预期：该提示不再出现在收藏区域，并且图标返回到未激活状态。

- [ ] FT-07：历史记录按时间顺序记录当前访问中查看的每个提示。
  - 操作：生成 3 个提示（可能跨越不同类别），然后检查历史记录区域。
  - 预期：列出了所有 3 个提示；每个条目显示类别和提示文本，按最新在前或最旧在前的顺序一致排列。

- [ ] FT-08：用户可以点击历史记录条目来重新查看该提示。
  - 操作：在历史记录中生成第二个提示后，点击第一个提示的历史记录条目。
  - 预期：显示区域再次显示第一个提示的确切文本。

- [ ] FT-09：用户可以在预定义类别之外添加一个新的自定义类别。
  - 操作：打开类别管理控件，创建一个名为“科幻小说”的新类别，然后确认。
  - 预期：“科幻小说”作为可选项出现在类别列表中，并且可以为它生成提示。

- [ ] FT-10：用户可以修改（重命名）现有类别。
  - 操作：编辑“头脑风暴主题”类别，将其名称更改为“创意孵化器”，保存。
  - 预期：类别列表现在显示新名称“创意孵化器”代替旧名称，且该类别仍然可选择并可用于生成。

- [ ] FT-11：用户可以删除一个类别。
  - 操作：删除一个自定义类别（例如“科幻小说”）。
  - 预期：该类别从类别列表中消失，不能被选中，也不能从中生成。

## 约束条件
- [ ] CS-01：不允许提交名称为空或仅包含空格的类别。
  - 操作：打开添加类别表单，将名称留空（或在字段中仅输入空格），尝试保存。
  - 预期：新类别未被创建；显示阻止它的验证消息，或者保存操作直接无效，保持之前的类别列表完整。

- [ ] CS-02：不允许创建与现有类别同名的类别。
  - 操作：再次尝试添加名为“诗歌”的新类别（已存在）。
  - 预期：应用程序拒绝重复项并显示错误消息（例如，“类别已存在”），类别列表中的项目数量没有增加。

- [ ] CS-03：不允许删除一个或零个类别（保护最后剩余的类别）。
  - 操作：重复删除类别直到只剩下一个，然后尝试删除最后一个类别。
  - 预期：最后一个类别无法删除——删除控件被禁用/隐藏，或者显示解释性消息。

- [ ] CS-04：在没有选择类别的情况下不允许生成提示。
  - 操作：在没有活动/选中类别的情况下加载页面（或者在清除选择后），尝试点击生成。
  - 预期：生成按钮被禁用或应用程序显示提示（例如，“请先选择一个类别”），并且没有生成空的或不属于任何类别的提示。

- [ ] CS-05：不保存任何内容时，收藏夹和当前访问的历史记录在重新加载后均为空。
  - 操作：生成 2 个提示并收藏其中一个，然后刷新页面。
  - 预期：历史记录区域为空（没有上一个会话的条目）且收藏夹为空，符合“当前访问”的作用域。

## 交互性
- [ ] IX-01：选定的类别在视觉上被高亮显示为活动状态。
  - 操作：点击“奇幻风景”类别卡片。
  - 预期：所选类别具有清晰的高亮/选中样式（例如，边框或背景颜色改变），与其他未选中的类别不同。

- [ ] IX-02：在点击生成后，会出现带有反馈的加载/生成状态。
  - 操作：点击生成并立即观察提示区域。
  - 预期：提示区域短暂显示加载指示器或“正在生成……”状态，然后被最终的提示文本替换（而非卡在该状态）。

- [ ] IX-03：收藏该提示会显示即时的成功反馈。
  - 操作：点击提示上的收藏图标。
  - 预期：图标填充/改变颜色，且/或者出现确认提示（例如，“已添加到收藏夹”）；不需要重新加载页面。

- [ ] IX-04：成功执行管理操作（添加/编辑/删除类别）后，会显示确认信息。
  - 操作：添加一个新类别，编辑一个类别，然后删除一个类别，观察每次之后的通知。
  - 预期：针对每个操作出现成功确认提示（例如，“类别已添加”、“类别已更新”、“类别已删除”）。

- [ ] IX-05：如果当前显示的提示为空，历史记录和收藏面板会予以明确说明，而不是显示为空白。
  - 操作：刷新页面（历史记录/收藏夹清空），查看两个面板。
  - 预期：面板显示空状态消息，例如“No prompts yet”（还没有提示）或“No favorites yet”（还没有收藏），而不是一个没有任何解释的空白区域。

## 内容
- [ ] CT-01：所有生成的提示在主题上都与其类别相匹配。
  - 操作：从每个预定义类别中生成至少一个提示，并阅读每个结果。
  - 预期：每个提示都合理地属于其源类别——短篇故事暗示了情节/人物，诗歌暗示了诗歌形式，角色素描暗示了人物特征，奇幻风景暗示了幻想环境，头脑风暴暗示了创意构思话题——没有不匹配的情况（例如，在“奇幻风景”中出现预算技巧提示）。

- [ ] CT-02：每个生成的提示都是实质性且完整的。
  - 操作：检查至少 5 个生成的提示文本。
  - 预期：每个提示都是一个可读的、完整的句子或短语，至少有几个词，没有截断，没有占位符文本（例如，“TODO”、“lorem ipsum”），也没有空字符串。

- [ ] CT-03：收藏夹和历史记录条目显示正确的类别标签以及提示文本。
  - 操作：从一个已知类别收藏一个提示，然后在收藏列表和历史记录中查看该条目。
  - 预期：这两个条目在提示文本旁边显示正确的源类别名称，并且在返回查看时提示文本完整且未被更改。

- [ ] CT-04：页面正确呈现应用标题、说明以及所有主要部分的标签。
  - 操作：查看页面页眉并扫描主区域。
  - 预期：存在可见的标题/标题（例如，与“创意提示生成器”相关的名称），并且四个区域被清晰地标记为类别、生成区、收藏夹和历史记录，没有错别字或缺失的部分标题。
