  - Expected: The transaction is not saved, and a validation error identifies the missing required fields.

    - Actual: With category left as "Select category", the dialog closed and a row "Nov 9, 2026 | Validation Test Entry | (empty category) | — | -$50.00" was saved into the list with no error message anywhere in the DOM (the test row was subsequently deleted).
